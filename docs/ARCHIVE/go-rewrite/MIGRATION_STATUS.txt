SQLite Column Name:    "channelValues"  (NOT "channel_values")

This is a quirk of the original Prisma schema where the field wasn't 
explicitly mapped. Go correctly handles this with explicit mapping:

    Prisma:  channelValues String @default("[]")
    SQLite:  "channelValues" TEXT NOT NULL DEFAULT '[]'
    Go:      ChannelValues string `gorm:"column:channelValues"`

Status: ✅ Correctly mapped in Go implementation
