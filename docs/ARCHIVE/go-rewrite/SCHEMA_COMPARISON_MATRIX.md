## Column Name Mapping - Special Cases

### Standard Mapping (Snake Case)
```
Prisma Field → SQLite Column → Go Field
────────────────────────────────────────
createdAt    → created_at      → CreatedAt
updatedAt    → updated_at      → UpdatedAt
userId       → user_id         → UserID
projectId    → project_id      → ProjectID
```

### ⚠️ Exception: channelValues (CamelCase)
```
Prisma Field  → SQLite Column   → Go Field        → GORM Tag
──────────────────────────────────────────────────────────────
channelValues → channelValues   → ChannelValues  → column:channelValues
              (NOT channel_values!)
```

**Why?** The Prisma schema didn't use `@map("channel_values")`, so Prisma created a camelCase column. Go correctly maps to this with explicit GORM tags.

## Foreign Key Comparison

### Example: fixture_instances → fixture_definitions

**Prisma Schema (Node):**
```prisma
model FixtureInstance {
  definitionId String            @map("definition_id")
  definition   FixtureDefinition @relation(fields: [definitionId], references: [id])
}
```

**SQLite DDL (Generated by Prisma):**
```sql
CONSTRAINT "fixture_instances_definition_id_fkey"
  FOREIGN KEY ("definition_id")
  REFERENCES "fixture_definitions" ("id")
  ON DELETE RESTRICT
  ON UPDATE CASCADE
```

**Go GORM Model:**
```go
type FixtureInstance struct {
    DefinitionID string              `gorm:"column:definition_id;index"`
    Definition   *FixtureDefinition  `gorm:"foreignKey:DefinitionID"`
}
```

**GORM Generated Constraint:** (reads existing FK from database)
```sql
CONSTRAINT "fixture_instances_definition_id_fkey"
  FOREIGN KEY ("definition_id")
  REFERENCES "fixture_definitions" ("id")
  ON DELETE RESTRICT
  ON UPDATE CASCADE
```

**Result:** ✅ Identical behavior

## JSON Serialization Strategy

Both backends store complex data as JSON strings in TEXT columns:

### Tags (String Array)

**Prisma:**
```prisma
tags String? @default("[]")
```

**SQLite:**
```sql
"tags" TEXT DEFAULT '[]'
```

**Go:**
```go
Tags *string `gorm:"column:tags;default:[]"`
```

**Usage:**
```typescript
// Node
const tags = JSON.parse(fixture.tags || "[]");
```
```go
// Go
var tags []string
json.Unmarshal([]byte(*fixture.Tags), &tags)
```

### Channel Values (Int Array)

**Prisma:**
```prisma
channelValues String @default("[]")
```

**SQLite:**
```sql
"channelValues" TEXT NOT NULL DEFAULT '[]'
```

**Go:**
```go
ChannelValues string `gorm:"column:channelValues;default:[]"`
```

**Storage Example:**
```
"[255, 128, 64, 0]"  ← Stored as TEXT
```

**Result:** ✅ Both use identical JSON serialization

## SQLite Pragma Compatibility

Both backends use identical SQLite configuration:

| Pragma | Node (Prisma) | Go (GORM) | Effect |
|--------|---------------|-----------|--------|
| `journal_mode` | `WAL` | `WAL` | Write-Ahead Logging for concurrency |
| `synchronous` | `NORMAL` | `NORMAL` | Balanced safety/performance |
| `busy_timeout` | `5000` | `5000` | 5 second wait on locks |

**Connection String (Node):**
```
file:./prisma/dev.db?_journal_mode=WAL&_synchronous=NORMAL&_busy_timeout=5000
```

**Connection String (Go):**
```go
dsn := fmt.Sprintf("%s?_journal_mode=WAL&_synchronous=NORMAL&_busy_timeout=5000", dbPath)
```

**Result:** ✅ Identical configuration
